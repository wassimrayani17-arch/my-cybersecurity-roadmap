\# Task Tracker API



A lightweight RESTful API built with Python and FastAPI for managing daily tasks and simple to-do lists.



\## Features



\- Full CRUD operations (Create, Read, Update, Delete)

\- Data validation powered by Pydantic

\- Interactive OpenAPI documentation out of the box
